FUNNGRO WEBSITE REVAMP — SUBMISSION GUIDE
===========================================

FILES
-----
index.html   = Company / Brands page
teen.html    = Young Talent page
style.css    = Complete responsive styling
script.js    = Small JavaScript interaction
SEO-Audit-Report.txt = SEO report for submission

HOW TO TEST
-----------
1. Keep all files in the same folder.
2. Open index.html in Chrome.
3. Click "For Young Talent" to open teen.html.
4. Test the buttons and links.
5. Resize the browser to check mobile responsiveness.

HOW TO PUT IT ONLINE — EASIEST METHOD
--------------------------------------
Use a static hosting service such as GitHub Pages or Netlify.

GitHub Pages:
1. Create/login to GitHub.
2. Create a NEW PUBLIC repository, e.g. "funngro-revamp".
3. Upload index.html, teen.html, style.css and script.js.
4. Open repository Settings → Pages.
5. Select "Deploy from a branch".
6. Select the main branch and root folder.
7. Save and wait for deployment.
8. Copy the generated website URL.
9. Put that URL in the Funngro project remarks.

BEFORE SUBMISSION
-----------------
- Replace the example.com canonical URLs in both HTML files with your actual deployed URL.
- Check the website on your phone.
- Check that both pages open correctly.
- Submit the deployed link.
- Upload/attach the SEO Audit Report if the project platform allows attachments; otherwise paste the report in the remarks if requested.

DESIGN IDEA
-----------
The redesign uses a dark premium visual system, bright green accent, large typography,
rounded cards, responsive layouts and a clear separation between the brand and young-talent
experiences. It is a concept redesign, not a copy of Funngro's existing source code.
